# vaults.cash — Overview (source of truth)

_Last updated: 2026-07-03. Living document — update alongside code changes._

## What it is

Consumer app for **Robinhood Chain** (chain id **4663**): log in with email,
pick a market (tokenized stocks or ETH), one tap converts USDG into an earning
Uniswap v4 LP position. Robinhood-grade UX over vfat-style mechanics.
Also fully usable by AI agents (MCP + REST).

- Production: https://vaults.cash (Vercel, `prosperity-labs` team)
- Repo: https://github.com/worldclasstom/vaults-cash (private)
- Chain: Arbitrum-stack L2, ETH gas, ~250ms blocks, ArbOS 61 (EIP-7702 live)
- Explorer: https://robinhoodchain.blockscout.com

## Revenue

**0.6% platform fee** on the USDG converted at deposit, and on the swapped
output at withdrawal (~0.45–0.9% round trip depending on range). Single
on-chain transfer to the fee wallet inside each atomic batch. **50% of fees
from referred users** is earmarked for the referrer (off-chain ledger, manual
payouts for now). Benchmark: vfat charges 0.09% + performance fees.

## Architecture (one screen)

| Layer | Choice | Notes |
|---|---|---|
| Auth + wallets | Privy embedded EOA | any-EVM via `defineChain`; smart-wallet product NOT yet on 4663 |
| Account model | EIP-7702 → EF Simple7702Account (`0xe6Ca…555B`) | same address forever; atomic batches |
| Execution | ERC-4337 userOps via Alchemy bundler, EntryPoint v0.8 (`0x4337…f108`) | Privy signs EIP-712 userOp + 7702 auth; sequential per-tx fallback retained |
| AMM | Uniswap v4 (official deployment) | pools use native ETH or token vs USDG; **sort order varies** (`assetIsCurrency0`) |
| Data | pool ticks via StateView; GeckoTerminal stats; Blockscout NFT enum | no Graph subgraph on chain yet |
| DB | Neon Postgres (referrals only) | positions/balances always read from chain |
| RPC | browser → Alchemy (domain-allowlisted); server + localhost → public RPC | Alchemy rejects origin-less/unlisted origins |
| Agents | MCP `https://vaults.cash/api/mcp/mcp` + REST `/api/agent/*` + `/llms.txt` | stateless; agents sign returned call batches |

## Money flow (deposit)

`approve USDG→Permit2 → Permit2→Router → V4_SWAP (range-ratio share) →
Permit2→PositionManager → mint position NFT → 0.6% fee transfer (LAST)` —
one atomic userOp; slippage-bounded; dust stays in the user's wallet.

## Compliance posture

Stock tokens (RHJ Jersey issuer) may not be offered to US persons —
geofenced in [src/proxy.ts](../src/proxy.ts) (US/CA/GB/CH/AE, derived from
the market registry) + disclosures page. Legal review required before
public marketing. ETH market is unrestricted.
